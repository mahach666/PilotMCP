# PilotMCP

MCP-сервер для работы с Pilot-ICE через Server API. Позволяет LLM-агентам подключаться к серверу Pilot, выполнять поиск, создавать и изменять объекты, работать с документами, историей изменений, правами доступа и чатами. Работает по транспорту stdio.

## Возможности

- Поиск и навигация по объектам; результаты больших выборок сохраняются в JSONL-файлы, а не передаются в контекст модели.
- Создание и изменение объектов, атрибутов, файлов, связей, задач, workflow, запросов на подпись.
- Документы XPS и PDF: извлечение текста с координатами, изображение страницы, замечания (аннотации) в формате Markup клиента Pilot 26.20+ и в старом формате.
- История изменений, права доступа, чаты и сообщения, настройки, отчёты `.repx`, автоматизации.
- Администрирование через админский API сервера: пользователи и оргструктура, типы, атрибуты, состояния, машины состояний.
- Режим только чтения (`PILOT_READONLY`), блокирующий все операции записи.

Полный список: [справочник инструментов](tools/index.md).
